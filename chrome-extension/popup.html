正方教务 · 通用选课助手

检测中…
  1. 登录教务系统后，不在选课页也会自动把你送到「自主选课」
  2. 在面板「账号」里填好学号密码 → 点「保存并登录」
  3. 添加目标 → 填课程名 → 点「预览匹配」确认教学班
  4. 取消勾选「仅演练」→ 点「开始抢课」
不用点页面上的「查询」按钮：扩展直接调用查询接口自己取课程列表， 按钮被遮住、在手机视口外、或者页面脚本没跑起来，都照样能查。
参数缺失时会自动从服务器页面补齐，并在面板日志里说清楚缺了什么。
掉线自动重登：抢课途中如果登录态失效，会自动重新登录并接着抢。
密码默认只存在内存里（关闭浏览器即清空），且网页读不到；勾「记住密码」才会持久保存。
目标卡片 ⚙ 里还能做更多：按星期 / 节次 / 周次精确挑教学班（支持单双周）， 勾「本地避开冲突」会用本地课表算一遍省一次往返，填「替换课程号」就是换课（骑驴找马）。
定时开抢：填个时刻，到点才开始发请求。
「冲突时自动退可退选修课」默认关闭：开了也只退 kklxdm=10 且 rwlx=2 的通识选修，必修永远只告警不动手。退选不可逆，先演练。
面板跑在页面里，直接用你当前已登录的会话。
配置存在扩展自己的存储里（chrome.storage），不碰网站的 localStorage。
